# ИИ-трейдер на бумаге: шесть ролей против «купил и держу»

Эксперимент по мотивам постов вида «6 ботов Grok превратили 23 000 ₽ в 279 000 ₽ за ночь».
Цель — честно проверить, зарабатывает ли такая схема. **Только виртуальные деньги.**

## Как устроено

| Часть | Где работает | Цена |
|---|---|---|
| Движок `engine.py`: цены, стопы/цели, исполнение заявок, график | GitHub Actions, каждый час | бесплатно (публичный репозиторий) |
| «Мозг» — шесть ролей и главный бот (`AGENT_PROMPT.md`) | запланированный сеанс Claude, раз в 4 часа | лимит подписки Claude, без платного API |
| Страница с результатами `bot/index.html` | GitHub Pages | бесплатно |

Два рынка, на каждом два счёта по $1 000:
- **ai** — решения шести ИИ-ролей (сканер, аналитик новостей, планировщик выхода, риск-менеджер, спорщик, главный бот);
- **rules** — контрольный бот без ИИ (`rules.py`: тренд + импульс + стоп по ATR).

Ориентиры: «купил и держу» BTC (крипта) или SPY (акции) и корзина всех тикеров поровну.

Честность симуляции:
- комиссия 0,1% и проскальзывание 0,05% на каждую сделку;
- если в одной часовой свече задеты и стоп, и цель — считается, что сработал стоп;
- гэп за стоп исполняется по цене открытия свечи;
- ИИ видит только данные до момента снимка, а исполнение идёт по следующей ежечасной цене;
- жёсткие лимиты (≤3 позиции, ≤30% на позицию, стоп 1,5–15%) проверяет код, а не промпт.

Почему нет бэктеста на истории: языковая модель «помнит» цены прошлых лет, поэтому такой бэктест
завышает результат. Проверка идёт только вперёд. Выводы — не раньше чем через 2–4 недели.

## Данные

Всё хранится в ветке `paper-trading` (main не засоряется):
`<рынок>/<ai|rules>/{state,equity,trades}.json`, `<рынок>/snapshot.json`,
`<рынок>/ai/orders.json` и журнал решений `<рынок>/ai/decisions.jsonl`.

Источники: Coinbase Exchange (свечи крипты), Yahoo Finance (свечи акций), RSS CoinDesk/Cointelegraph/Decrypt/Yahoo (новости). Ключи не нужны.

## Локальная проверка

```bash
pip install -r bot/requirements.txt
MOCK_DATA=1 STATE_DIR=/tmp/pt python bot/engine.py tick      # синтетические данные
STATE_DIR=/tmp/pt python bot/engine.py validate               # проверка заявок ИИ
```

Это эксперимент, а не инвестиционная рекомендация.
